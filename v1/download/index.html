MethodEndpointDescriptionAuthFormatTry
GET /api/v1/water-bodies List all water bodies with filtering API Key JSON/GeoJSON
GET /api/v1/water-bodies/{id} Get specific water body by permanent ID API Key JSON/GeoJSON
GET /api/v1/monitoring-stations List monitoring stations API Key JSON/GeoJSON
GET /api/v1/monitoring-data/{stationId} Get monitoring time-series data API Key JSON
GET /api/v1/permits List water permits (filtered by role) Bearer JWT JSON
GET /api/v1/measures List programme of measures API Key JSON
GET /ows/wms OGC WMS - Map tile service None (public) PNG/GeoTIFF
GET /ows/wfs OGC WFS - Feature service API Key GeoJSON/GML

Example Request

# Get all river water bodies in Vardar Basin
curl -H "X-API-Key: your_api_key"
  "https://wis.moepp.gov.mk/api/v1/water-bodies?basin=VAR&type=river&format=geojson"

# Response:
{
  "total": 89,
  "page": 1,
  "data": [
    { "id": "MK-VAR-RW-001", "name": "Vardar - Negotino", ... }
  ]
}
