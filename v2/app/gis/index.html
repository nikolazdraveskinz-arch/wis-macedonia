ToR Task 4. Spatial layers are stored in the database (vector datasets used for linking, querying and reporting) or in the file system with a tile cache (large rasters), and linked to attribute data through permanent identifiers. Spatial editing stays in desktop GIS (QGIS, ArcGIS); the NWIS uploads, validates, publishes and controls access. The GIS Configurator decides which layer appears in which application and for which role.

Spatial layers keep only geometry and the permanent identifier; descriptive attributes live in the database tables and are joined by ID (NWIS Report recommendation).

Two settings per layer: where it is used (applications) and who may see it (lowest role with access, and the attribute level shown to the public). The same rules apply in the map viewers, WMS/WFS services and the API.
