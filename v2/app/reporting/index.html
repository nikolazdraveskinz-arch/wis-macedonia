Republic of North Macedonia · Ministry of Environment and Physical Planning

WISE reporting – foreseen in a later phase

Automatic and semi-automatic generation of WISE reporting datasets is Phase 3 of the NWIS roadmap and is not part of the current development (ToR, Phase 1). Submission would be coordinated through NEIS.

What Phase 1 already prepares
  • Permanent identifiers for all WISE-relevant entities (water bodies, sites, pressures, protected areas, measures, reporting units)
  • WISE-aligned code lists (pressure, impact and KTM enumerations) in Reference Data
  • Reporting period, version and source stored on every dataset
  • A data model planned for later export to WISE schemas (NWIS Report, RDBMS action 6)
