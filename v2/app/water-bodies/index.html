WFD Status Classification Note
Status classification follows the WFD Annex V biological quality elements, supported by physico-chemical and hydromorphological supporting elements. Classification is based on the ICES approach using national boundary setting and intercalibration results agreed under EU WFD CIS process.
Permanent identifiers are immutable after assignment. They follow the INSPIRE WFD schema: MK-{BASIN}-{TYPE}-{NUMBER}

Identifier Schema

MK — Country code (ISO 3166-1)
VAR/BLA/STR/BRE — Basin code
RW/LW/GW — Water body type
001..999 — Sequential number
Example: MK-VAR-RW-001
